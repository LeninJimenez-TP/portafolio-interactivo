# Portafolio Interactivo - PC3 (Hojas de Estilo en Cascada Avanzado)

## Descripción del Proyecto
Landing page desarrollada de manera responsiva utilizando **Bootstrap 5**, aplicando conceptos avanzados de CSS como transformaciones 2D/3D y animaciones personalizadas mediante `@keyframes`.

## Tecnologías y Efectos Aplicados:
1. **Bootstrap 5:** Uso de Navbar colapsable en dispositivos móviles, sistema de Grid (`container`, `row`, `col`) y formulario estilizado.
2. **Transformaciones 2D:** Efectos de `rotate`, `scale` y `skew` aplicados en tarjetas con una transición suave de `0.5s`.
3. **Transformaciones 3D:** Contenedor con `perspective: 1000px` y `transform-style: preserve-3d` que rota sobre los ejes X e Y al hacer *hover*.
4. **Animaciones CSS:** 
   - Animación de carga circular (`loader`) infinita mediante `@keyframes`.
   - Animación personalizada de opacidad y desplazamiento para el título principal.
